    Foundation

    A great terminal first.

    A blank slate, not a blank start. Slate is useful before you extend anything.

    • Powered by libghosttyGhostty terminal surfaces in native AppKit windows.
    • Tabs, splits and zoomNested panes, directional focus, zoom for the one that matters.
    • ⌘K command pickerFuzzy search across every command, in Liquid Glass.
    • Browser panesPreview a site or read the docs next to your shell.
    • Saved layoutsSave an arrangement and open it from a Spotlight launcher.

    How it works

    Your agents build. Slate connects the pieces.

    A plugin system and CLI give you and your agents a direct way to add panels, commands and interfaces where you already work.

    Plugins

    Panels, commands and background services that sit in panes like a terminal.

    The CLI

    slate-term registers plugins, arranges panes and saves layouts from any shell.

    Your agents

    A Slate skill teaches the agent you bring the API. Slate doesn’t include a model.

     what your agent runsIllustrativeflags abbreviated
    # Register the plugin it just wrote, then place its panel
$ slate-term plugins register --manifest ~/slate/deploys/plugin.json
$ slate-term panes split --pane p1 --right --type deploys

# Change it, reload it, keep working
$ slate-term plugins restart deploys

# Save the arrangement and open it later from Spotlight
$ slate-term layouts capture --window W1 --name 'Launch Day'
$ slate-term layouts launcher --id ID --path ~/Applications/Launch\ Day.app
✓ Launch Day.app
