    02 Range

    Three tools, three shapes.

    Some tools sit quietly next to your shell. Some put buttons on a script. Some grow until they’re the main event.

    01 / Beside the terminal

    Keep your agents in view.

    A panel that lists each agent session, what it’s working on, and what’s waiting for your review. It sits next to the terminals the agents run in, so nothing gets lost in a tab you forgot about.

    plugin panel · data pane titles, events

    02 / On top of a script

    Give a shell script an interface.

    Inputs, a run button, and a results table for a script you already trust. The script stays the source of truth. The panel just makes it easier to use and to share with the next person.

    plugin panel + command · runs ./resize-assets.sh

    03 / The whole window

    Let the idea take the window.

    An experiment workbench that compares runs and charts results. Give it most of the window while it’s the focus. Keep a terminal at the edge for the training job, and change the tool as you learn what you need.

    plugin panel + background service

    03 Foundation

    A terminal first.
    Everything else is optional.

    Before you build anything, Slate is a terminal you’d want to use: Ghostty’s engine in native AppKit windows, with tabs, splits and a command picker that stay out of the way. Extend it when it helps, not because you have to.

    Engine 01

    libghostty

    Real Ghostty terminal surfaces, embedded in native windows.

    Windows 02

    AppKit, native

    Native windows and tabs. Your workspace is restored after a restart.

    Panes 03

    Split · Zoom

    Nested splits, directional focus, zoom and equalize. Drag a pane by its grip to move it.

    Commands 04

    ⌘K picker

    Keyboard-first, in Liquid Glass. Fuzzy search across built-in and plugin commands.

    Browser 05

    WebKit panes

    Preview localhost beside your shell, with a persistent or a private profile.

    Settings 06

    TOML, live

    Typed settings for fonts, themes and shortcuts. Changes reload while you work.

    Layouts 07

    Saved layouts

    Save an arrangement and open your workspace from a Spotlight launcher.

    Automation 08

    slate-term

    A bundled CLI over a private, same-user control socket.

    macOS · Apple Silicon · in active development Production note Confirm supported macOS versions before launch.

    04 Mechanism

    Your agent builds.
    Slate connects the pieces.

    Plugins provide the interfaces and commands. The CLI lets you, or your agent, arrange the workspace around them. Nothing is hidden behind a chat window.

    ▣

    Plugins

    Add panels, commands and background services. Panels are web pages with a bridge to the workspace, and they sit in panes just like a terminal.

    ›_

    CLI

    slate-term splits and moves panes, opens panels, drives browser panes, waits on commands and saves layouts, from any shell.

    ✻

    Your agents

    Install the Slate Terminal skill and your agent can discover the API, write a plugin, register it and put it where you need it.

    05 Iteration

    Use it.
    Change it.
    Keep going.

    Your first version is a starting point. Building, using and refining become one continuous process, in the same window.

    3. 03

    06 For your agents

    Bring your own agents.

    Slate doesn’t include a model or a chat window. It gives the agents you already use a workspace they can see and change, through the same commands you can run yourself.

    • Inspect panes and read what’s on screenpanes inspect · context inspect
    • Split, move and rename panespanes split · panes move
    • Register a plugin and open its panelplugins register
    • Navigate and check a browser panebrowser navigate
    • Wait for a command to finishterminal wait
    • Tell you when it’s donenotify
    • Save the arrangement for laterlayouts capture
    Bring Claude CodeCodexGemini CLIopencodeyour own scripts

    Examples, not tested integrations. If your agent can run a shell command, it can call slate-term.
