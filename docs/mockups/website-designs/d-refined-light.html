    Foundation

    A great terminal first.

    Native on macOS and useful before you extend anything.

    • Powered by libghosttyReal Ghostty terminal surfaces in native AppKit windows.
    • Tabs, splits and zoomNested panes, directional focus, and zoom for the one that matters.
    • ⌘K command pickerFuzzy search across every command, in Liquid Glass.
    • Browser panesPreview a site or read the docs next to your shell.
    • Themes and TOML settingsFonts, themes and shortcuts reload live as you edit.
    • Saved layoutsSave an arrangement. Open it again from a Spotlight launcher.

    How it works

    Your agents build. Slate connects the pieces.

    Plugins

    Panels, commands and background services, with an optional UI kit that matches your theme.

    The CLI

    slate-term registers plugins, arranges panes and saves layouts. Anything that runs a shell command can use it.

    Illustrative
    what your agent runs
    # Register the plugin it just wrote, then place its panel
$ slate-term plugins register ./plugins/deploy-tail
$ slate-term panes split --pane p1 --right --type deploy-tail

# Change it, reload it, keep working
$ slate-term plugins restart deploy-tail

# Save the arrangement and open it later from Spotlight
$ slate-term layouts capture --name 'Launch Day'
$ slate-term layouts launcher --path ~/Applications/Launch\ Day.app
✓ Launch Day.app
