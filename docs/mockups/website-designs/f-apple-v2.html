Demo: ask your agent for a tool, then use it

Illustrated example workflow. In a Slate terminal, the user starts Claude Code and asks for a panel that tails deploys. In time-lapse, the agent writes a plugin, opens it as a panel and checks it, with a tag on the pane showing what the agent is doing. It then adds a latency chart and an agent task board when asked. At real speed, the user approves a task while tags show Codex and Claude working in the Deploys panel, inspects the chart, saves the layout from the command picker, and reopens it from a Spotlight launcher. Three proposed examples follow: an agent-workflow panel, an interface for a script, and an experiment workbench.

    Your agents build. Slate connects the pieces.

    Your agent writes the plugin. The slate-term CLI puts it in place.

    claude — launchpadIllustrative
    ❯ claude
> Tail my deploys in a panel beside this shell, then save the layout.

● Write(deploy-tail/plugin.json, deploy-tail/index.html)
● Bash(slate-term plugins register --manifest ./deploy-tail/plugin.json)
  ⎿ registered deploy-tail
● Bash(slate-term panes split --pane p1 --right --type deploy-tail)
  ⎿ opened p2
● Bash(slate-term layouts capture --window w1 --name 'Launch Day')
● Bash(slate-term layouts launcher --id L3 --path ~/Applications/Launch\ Day.app)
  ⎿ created Launch Day.app

✓ Deploys is open on the right. Launch Day is in Spotlight.
