    Your agents build. Slate connects the pieces.

    Plugins add panels and commands. The slate-term CLI lets any agent put them in place.

    zsh — launchpad
    # Register the plugin your agent wrote, then dock it
$ slate-term plugins register --manifest ./deploy-log/plugin.json
$ slate-term panes split --pane p1 --right --type deploy-log

# Save the arrangement with a Spotlight launcher
$ slate-term layouts capture --window w1 --name "Launch Day"
$ slate-term layouts launcher --id 5f3c… --path ~/Applications/Launch\ Day.app
✓ Launch Day.app
