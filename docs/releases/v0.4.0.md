# Slate Terminal 0.4.0

Find a tab with the new Show All Tabs command, and manage stored browser data directly in Settings.

## Workspaces

- Open the native tab overview from the command picker by searching for Show All Tabs. It is also available in the Workspace and Window menus and can be assigned a keyboard shortcut.
- Unnamed tabs now display New Tab.
- Choose your default working directory with a folder picker in Settings.
- Agent focus indicators blend when multiple agents target the same element.
- Agent activity now appears for asynchronous terminal commands and additional pane actions. Asynchronous command indicators stay visible until the command finishes.
- Fixed `terminal start --shell` rejecting its shell-language assertion.
- Improved shell reporting under strict Bash settings and stopped leftover report helpers after their shell exits.

## Browser

- Settings lists sites with stored shared browsing data. Remove a selected site's data even when that site is no longer open.
- Automation can inspect stored sites with `browser.listData` and remove a site's data with `browser.removeSiteData`.

Requires Apple Silicon and macOS 27 or later. Updates require an explicit **Install and Relaunch** confirmation.
