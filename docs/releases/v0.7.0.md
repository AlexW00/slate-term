# Slate Terminal 0.7.0

- Restore saved terminal output directly above the new shell prompt, with normal scrolling, selection and search. Output retention now lives in General settings when workspace restoration is enabled.
- Create App shows a live icon preview and uses the native save dialog to choose the app’s name and location.
- Restore a layout app’s windows to its saved layout from the command picker or CLI. Running processes require confirmation, and private settings, browser data and plugin data are retained.
- Enable or disable inherited plugins independently in each layout app. Local choices survive parent synchronization and restart.
- Layout-app Settings clearly disable recipe editing while keeping tabs and panes available for inspection.
- Remove stored website data with a trash button on each site row, or use Clear All Site Data.
- Place browser agent indicators closer to the bottom bar and improve bundled agent guidance for keeping pane activity visible.

Requires Apple Silicon and macOS 27 or later. Restored terminal output is historical text; it does not resume old processes or replay commands.
