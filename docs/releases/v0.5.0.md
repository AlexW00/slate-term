# Slate Terminal 0.5.0

Keep working while agents arrange the workspace, with quieter activity indicators and adjustable pane dimming.

## Workspaces

- Automation preserves your active pane, tab and window when creating splits, tabs or windows, moving background panes, or opening saved layouts.
- Background layout changes preserve keyboard focus in Settings and existing editors.
- Adjust unfocused-pane dimming in Settings → Appearance. The default is 8%; set it to 0 to turn dimming off.

## Agent activity

- Agent names stay stable without changing pane-ID suffixes.
- Holds use a centered breathing diamond without a text label. Reduce Motion keeps the diamond still.
- Activity outlines follow rounded window corners, and success checkmarks use a neutral color.
- Agent guidance clarifies identity across fresh tool shells, focus preservation, and use of Slate's browser for previews and browsing.

## Automation compatibility

Structural commands now preserve focus by default. Scripts that intentionally select newly created content should request `focus: "new"`; pane moves should request `focus: "target"`. The CLI exposes these as `--focus-policy` where applicable. Explicit focus commands and native keyboard/menu actions retain their intentional selection behavior.

Requires Apple Silicon and macOS 27 or later. Updates require an explicit **Install and Relaunch** confirmation.
