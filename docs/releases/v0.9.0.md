# Slate Terminal 0.9.0

## Added

- Open a new workspace window from Slate Terminal’s Dock menu, even when all windows are closed.

## Fixed

- Restore all four pane-move drop targets over browser and plugin content.
- Give foreground terminal jobs time to exit gracefully when Slate closes, and preserve their final output in restored scrollback without duplicate snapshots.

Requires Apple Silicon and macOS 27 or later.
