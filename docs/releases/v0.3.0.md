# Slate Terminal 0.3.0

New splits open in the directory you are working in, with more control over tabs, panes, and browser data.

## Workspaces

- New terminal splits inherit the current directory of the terminal being split. Choose a default directory or turn off inheritance in Settings.
- Rename tabs from their native context menu.
- Restore a maximized pane with a button in its header.
- Keep your place in the command picker while commands refresh in the background.
- Saved-layout previews stay in place when toggling pane bars, and clicking empty pane-header space no longer starts renaming.

## Browser and agents

- Clear all shared browser data or data for a selected site from Settings. Private Browser panes and plugin storage remain separate.
- Agent activity indicators stay visible longer and follow newly created splits.

Requires Apple Silicon and macOS 27 or later. Updates require an explicit **Install and Relaunch** confirmation.
