# Slate Terminal 0.8.0

- Choose files and folders with native upload dialogs in browser and plugin panes.
- Download attachments, generated files and other browser downloads through a native save dialog. Track progress or cancel from Downloads in the toolbar or command picker.
- Use JavaScript alerts, confirmations and text prompts in browser and plugin panes.
- Open login and other popup flows in separate browser windows while retaining their opener and session. Private-browser popups share only their originating private session.
- Control uploads, downloads, dialogs and popup windows through the shared API, CLI and trusted plugin bridge, with stale-request protection.
- Find Refresh Browser in the command picker, or use Command-R.
- Keep restored terminal output in ordinary scrollback. Remove the separate previous-output viewer and its Show/Clear commands and history-read/export APIs.

Requires Apple Silicon and macOS 27 or later. Popup support does not bypass websites that restrict embedded browsers. Restored terminal output remains historical text and never replays commands.
