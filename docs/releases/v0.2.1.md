# Slate Terminal 0.2.1

This release adds terminal search and history tools, restores more of your workspace, and improves how agents work with Slate.

## Terminals and workspaces

- Find text in a terminal and retrieve or export retained scrollback.
- Keep Bash command tracking working with history disabled and strict-mode startup settings.
- Reopen workspaces with their working directories, browser locations, and window positions.
- Edit saved layouts with clearer pane previews and per-pane working directories, then reopen them through dedicated launchers.
- Get started with a responsive SLATE welcome banner and clearer onboarding controls.

## Agents and plugins

- Start tracked terminal operations, reconnect to check their status, and wait for results without losing the operation when a client disconnects.
- Inspect complete machine-readable contracts for the shared API and commands, including in-app updates.
- Plugins can declare required API versions and capabilities. Slate checks compatibility before running them.

## Automation behavior changes

`terminal.capture` now returns the active screen. Use `terminal.history` when you need retained scrollback.

A `terminal.run` timeout or client disconnect ends the wait; the operation remains tracked and the pane stays busy until it settles. Submission failures are recorded as `submissionFailed`. Operation handles last for the current app and terminal session; they are not restored after restarting Slate.

## Updating

Updates still require an explicit **Install and Relaunch** confirmation. Release notes are now shared between GitHub and the in-app update window.

Requires Apple Silicon and macOS 27 or later.
