# Slate Terminal 0.1.0

The first release of Slate Terminal brings terminals, browser panes, and custom tools into one native macOS workspace.

## Your workspace

- Arrange terminals and browser panes in tabs and splits.
- Save layouts with working directories and reopen them from dedicated launchers.
- Add custom panels, commands, and background services with plugins.
- Control the workspace through the CLI and shared automation API.

## In-app updates

Choose **Check for Updates…** from the Slate menu to read release notes and download an update. Slate verifies the download before offering **Install and Relaunch**. Installation starts only after you confirm; closing the update window or quitting Slate does not install a staged update.

This release establishes the update channel. Future releases will appear here once they are published.

Requires Apple Silicon and macOS 27 or later.
