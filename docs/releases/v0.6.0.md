# Slate Terminal 0.6.0

- Turn saved layouts into independent Mac apps with their own windows, terminal sessions, browser profiles, and plugin data. Their settings and plugins follow Slate Terminal, with local setting overrides.
- Manage layout apps from Settings or the CLI. Apps keep a stable identity while applying compatible runtime updates from Slate Terminal.
- Keep previous terminal output across relaunch and inspect it in a read-only history viewer. Configure how much output to retain.
- Customize agent accent colors in Settings, including colors for your own agent names. Ordinary activity now uses the same breathing diamond as explicit holds, with a static indicator for Reduce Motion.
- Improve update confirmation, plugin synchronization, and responsiveness during layout-app creation and refresh.

Requires Apple Silicon and macOS 27 or later. Each layout app has separate macOS permissions. Existing shortcut launchers continue to open their saved layout in Slate Terminal; create a new app to use independent sessions.
